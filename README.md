# 多臂老虎机与重尾在线学习笔记

这是一份关于多臂老虎机、在线学习与重尾反馈的个人学习笔记。

笔者是数学专业学生，因此笔记更侧重理论基础和数学推导，主要采用“定义—定理—证明”的方式组织内容。在介绍算法时，不仅记录算法形式，也尽量说明其假设、设计动机、证明思路以及遗憾界的含义。每章还整理了一些学习过程中产生的疑问与个人思考，希望帮助自己建立由概率论基础到在线学习论文阅读的完整知识链条。

## 主要内容

- 概率不等式、集中不等式与置信区间
- 随机平稳多臂老虎机与探索—利用权衡
- Explore-Then-Commit 与 UCB
- 对抗型多臂老虎机与 EXP3
- 重尾分布、截断均值与 Median-of-Means
- Robust UCB 与重尾遗憾界
- FTRL、log-barrier 与 uniINF 的初步学习
- 可重复实验的基本规范

## 编译方式

请将两个 `.tex` 文件保留在同一目录，并使用 XeLaTeX 编译主文件。为正确更新目录，建议连续编译两次：

```bash
xelatex 多臂老虎机与重尾在线学习笔记.tex
xelatex 多臂老虎机与重尾在线学习笔记.tex
```

中文排版依赖 `ctex`，建议使用较完整的 TeX Live 环境。
